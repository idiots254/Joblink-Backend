# Joblink Project

## Overview
Joblink is a web application that provides a user-friendly login interface. This project includes a styled login page with responsive design, ensuring a seamless experience across devices.

## Project Structure
```
joblink
├── src
│   └── Login
│       └── Login.css
├── index.html
├── package.json
└── README.md
```

## Setup Instructions

1. **Clone the Repository**
   ```bash
   git clone <repository-url>
   cd joblink
   ```

2. **Install Dependencies**
   Make sure you have Node.js installed. Then run:
   ```bash
   npm install
   ```

3. **Run the Application**
   You can open the `index.html` file directly in your browser or set up a local server to serve the files.

## Usage
- Navigate to the login page to access the login form.
- The login page is styled using CSS located in `src/Login/Login.css`.
